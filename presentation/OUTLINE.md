# 《浏览器还能这么用》内容蓝图 v3

> 场景：熟同事之间的技术分享，15 分钟讲完 + 之后聊天。
> 形态：本机实时演示为主，HTML 只做「过场」和「技术底牌」。
> 听众：数据方向为主，前端/后端都有，多数人接触过 AI 与新工具。

---

## 0. 定位

一句话：**我把一个看板塞进了新标签页，顺手试了下浏览器还能碰什么，想给大家看看。**

不是教学，不是汇报，不是布道。语气 = 跟同事在白板前聊"我最近弄了个东西，你看这个有意思吧"。

三个硬约束：
- 不设方法论章节、不设检查点、不用"闭环/抓手/升维"这类词
- 标题必须能直接念出来
- HTML 上不写大段内容 —— 内容在嘴上和屏幕上（实机演示）

## 1. HTML 的定位：三种页型

| 页型 | 作用 | 数量 | 设计 |
|---|---|---|---|
| **过场卡** | 切回屏幕时有个东西垫着，告诉观众"现在在哪" | 4 | 一个大标题 + 一行小字，其余全空 |
| **技术页** | 演示之后回来讲"刚才那东西凭什么能做到" | 3 | 一张表或一张清单，密但有秩序 |

节奏：空 → 空 → 密 → 空 → 空 → 空 → 密 → 密 → 密 → 讨论。

## 3. 逐页内容

### P1 封面
标题候选（挑一个，别贪）：
- 《浏览器还能这么用》
- 《一个看板，和它背后的四种数据》
- 《我把每天的几件事塞进了新标签页》

副标：*用 DSH 做的几个小东西，顺便看看浏览器的手能伸多长。*

### P2 浏览器里常见的东西有四种
一句话立题：**同一个念头，有四种落地方式，能力差别巨大。**

| 形态 | 是什么 | 能力边界 |
|---|---|---|
| 主题 / 皮肤 | 换外观 | 只能改颜色 |
| 起始页 / 新标签页 | 换"打开浏览器先看到什么" | 能展示，能取数 |
| 用户脚本（油猴） | 往别人的页面里塞一段 JS | 能改页面，拿不到浏览器 API |
| 扩展（MV3） | 一个有权限、有后台、能调本机的程序 | 几乎什么都能碰 |

底注（给没接触过的人）：扩展的门槛其实就是三个文件 —— 一个 `manifest.json` 声明"我要碰什么"，一个页面，一个脚本；改完点一下重载就生效，没有构建、没有部署。

### P3 这东西是 DSH 跟我聊出来的
- 我不会前端。manifest、content script、native messaging 这些词，我一开始一个都不知道。
- 真正起作用的是一份 42KB 的 `AGENTS.md` —— 我把每个坑写进去，它下次就不踩了。它不是文档，是给 AI 的项目宪法。
- 真正的变化不是"我写得快了"，是**"我不会"这个理由消失了**。

### P4 一个看板，四种数据（过场卡 + 演示入口）
```
                    ┌──────────────┐
   内部 (cygnus) ───│              │─── 外部 (cursor)
                    │  新标签页     │
   这台机器 (蓝牙) ──│              │─── 另一台机器 (SSH)
                    └──────────────┘
```
一句话：**一个看板，把浏览器能碰的四类地方都碰了一遍。**

> 演示（约 10 分钟，全场核心）：Ctrl+T → 拖卡片 / 折叠 → 点图标进设置页 → 依次指内部 cygnus 那行、Cursor 曲线、蓝牙电量、服务器磁盘。

### P5 这四类数据分别怎么拿到的
|  | 从哪来 | 凭什么能拿到 | 踩过的坑 |
|---|---|---|---|
| **内部** | cygnus 的 Release Matrix 接口 | 用你在浏览器里的登录态，由扩展在后台注入到请求头 | Django 认 `Origin`，扩展默认带的是 `chrome-extension://` → 直接 403 |
| **外部** | cursor.com 的 dashboard | 同上，你登录过就能读 | 扩展页面自己发请求时，带不上 Cookie |
| **这台机器** | PowerShell 读蓝牙电量 | 网页碰不到硬件 → 叫起本机的一个小程序 | 那个小程序得手动装一次，扩展不能替你装 |
| **另一台机器** | SSH 到服务器跑 `df` / `du` | 同上，小程序替你 ssh 过去 | 只能跑在浏览器所在的那台机器上 |

底注：所以"插件能做什么"其实取决于两件事 —— **浏览器给了什么权限**，以及**你在本机有没有一个帮手**。
另注：卡片能拖、能折叠，位置记在浏览器里；所有配置项在设置页，一个保存按钮。

### P6 顺便：两边价格摆一起（过场卡）
一句话：**安居客告诉我户型，贝壳告诉我同一个小区正在卖多少钱 —— 以前得开两个窗口对。**

> 演示：地图找房 → 点一个气泡 → 户型表 + 贝壳挂牌。

### P7 顺便：在别人页面里写字（过场卡）
一句话：**DeepSeek 的输入框，我能把一段文字直接塞进去，长文本它自己会变成附件。**
小字：还有一个叫「DeepSeek 下班了」的 —— 限额时把对话搬到另一个 AI 接着聊。

> 演示：会话页悬浮球 → 填入 / 转附件。

### P8 为什么偏偏是浏览器
1. **它本来就在你每天的路径上** —— 不是多装一个 App，是少一次"专门去打开"。
2. **它能同时碰到好几样东西** —— 网络、你的登录态、别的页面、剪贴板、本机程序。
3. **它的成本是三个文件加一次重载** —— 改一行，按一下，就生效。

### P9 它能碰什么（会被拍照的一页）
| 能碰 | 所以你可以想 |
|---|---|
| 标签页、地址栏 | 把"开五个站挨个看"缩成一次 |
| 页面内容（读） | 把散在网页里的数抄下来，不用手抄 |
| 页面内容（写） | 往别人的输入框里塞一段结构化结果 |
| 网络请求 + 你的登录态 | 内部系统的数据，不用再写爬虫和登录 |
| 剪贴板 | 一键把一段结果带走 |
| 本机程序 | 网页够不到的东西：文件、内网、硬件 |
| 下载、通知、快捷键 | 把一个小流程收成一个动作 |

底注：**前六项里，只有"本机程序"需要额外装东西。** 其余都是浏览器给的。

### P10 它也很脆
- 网站改版，解析就挂 —— 安居客的节点会被复用，我重写过一次。
- 平台限流，功能就废 —— 持仓那个现在基本不用了。
- 换台机器就得重装 —— 扩展的身份跟目录路径绑在一起。

一句话：**所以它是"个人工具"，不是"产品"。三个月后还能用，就算成功。**

### P11 外行管理内行（讨论页）
三段：
1. **那个类比**：体制内不懂业务但懂管理的领导，靠"提要求、验收、打回重做"拿到东西；你不会写插件，靠"提要求、验收、重试"拿到东西。同一套动作。
2. **它凭什么成立**：这个说法本来是贬义，因为它假设"内行会瞒你、外行要担责"。AI 把前者抹掉了 —— 它不会瞒你、不会糊弄你、也不会累。剩下后者（出了事还是你担责），才是真正的分界线。
3. **一个不太客气的说法**：以前是互联网改造传统行业，现在是**有领域问题的人自己拿起了工具**。真正稀缺的从来不是代码，是"知道什么值得做"和"能判断做得对不对"。

留给聊天的一句（放页脚，别放大）：*咱们做数据的，手里有哪些事是一直觉得"该有个工具"但一直没做的？*

## 5. 视觉方向

- **底**：接近新标签页的白 + 极淡网格（草图纸/白板），投影安全。
- **字**：超大标题，一页一个主张；技术页才出现表格。
- **注脚**：等宽体，小一号，像白板角落的小字 —— 技术细节都在这里。
- **强调**：琥珀色只给"坑"和"本机程序"用，全篇不超过五处。
- **不做**：四宫格卡片、图标墙、逐页动画堆叠、进度条。

## 6. 决策记录（来自讨论）

**语境**
- 熟同事之间，不是汇报、不是培训。判断标准：每句标题能不能直接在会上念出来。
- 时长：计划 30 分钟，实际讲 15 分钟，其余留聊天。
- 听众：数据方向为主，前端/后端都有，多数已接触 AI 与新工具 —— 基础概念点到即止。
- 内部信息（内网主机名、Cursor 花费、公司系统名）原样保留。

**形态**
- 不做动手环节：本机实时演示效果，HTML 不写大段内容（见 §1 的三种页型）。
- 演示顺序即结构顺序：看板（内部 / 外部 / 本地 / 远程 + 设置方式，约 10 分钟）→ 比价 → DeepSeek 操作。
- 看板是核心，后两者只用于"展示能做到什么"。

**结构演进**
- v1 能力阶梯 L0–L4 —— 有考核感，弃用。
- v2 三个接触面（自己的页面 / 别人的页面 / 浏览器之外）—— 演进为 v3 的四类数据来源：切分更贴合实际演示顺序，"本地 vs 远程"也比"浏览器之外"更有信息量。
- 新增 P11 讨论页：B 站《用AI=外行管理内行？》的类比 → 提炼 → 开放性说法 → 留一个问题。

**P11 已定的三个结论**
- 类比成立的关键：AI 抹掉了"内行会瞒你"这个前提，但没抹掉"外行要担责"。
- "反攻程序员"要留神的词：真正的分界不在"传统行业 vs 互联网"，在"有真问题的人 vs 只会实现的人"。
- 结尾不给结论，给问题（见 P11 页脚）。
